# All That Work website

Public product and founder overview at https://allthat.work, published through GitHub Pages from the root of `main`. No build step or dependencies.

To preview locally, run `python3 -m http.server 8791` in this directory and open http://localhost:8791.

The software lives at https://github.com/allthatwork/allthatwork. The organization profile is maintained separately in https://github.com/allthatwork/.github.

The screenshots are captures of the current All That Work development app using an isolated fictional Jordan Rivera account. The job-fit assessment is an illustrative seeded example, not a live assessment of a real person. No production data or private provider credentials are used. The underlying software is MIT licensed; the upstream notice is in `assets/UPSTREAM-LICENSE`. Brand assets are maintained in the project workspace's `brand/` directory.

DNS: apex A records point to GitHub Pages; `www` CNAME points to `allthatwork.github.io`. Email MX and verification TXT records are independent and must be retained.
